# Football Data Dashboard

A football analytics platform built with:

- Next.js
- TypeScript
- PostgreSQL
- Prisma
- Python

## Features

- Import football leagues from Football-Data.org
- Import teams from top European leagues
- Store data in PostgreSQL
- Display analytics dashboards

## Tech Stack

- Next.js
- TypeScript
- Prisma
- PostgreSQL
- Python
- Football-Data.org API
